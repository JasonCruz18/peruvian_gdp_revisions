# Dashboard Assets

Place your project logo and other assets in this folder.

## Logo

Add your project logo as `logo.png` in this directory. The dashboard will automatically display it in the header.

**Recommended specifications:**
- Format: PNG with transparent background
- Size: 200-400px width
- Aspect ratio: Horizontal layout works best

## Custom Fonts (Optional)

If you want to use custom fonts, place the font files here and reference them in `dashboard/config.py`.
