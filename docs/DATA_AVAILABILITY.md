# Data Availability Statement

**For Journal Submission**

## Data Sources

### Primary Data Source

The data used in this study comes from the **Central Reserve Bank of Peru (BCRP)** Weekly Reports (Notas Semanales), which are publicly available at:

**URL**: https://www.bcrp.gob.pe/publicaciones/nota-semanal.html

**Access**: Public domain, no registration required
**Format**: PDF files
**Frequency**: Weekly publications
**Coverage**: January 1992 - Present
**Language**: Spanish

### Data Collection

All data was collected using automated web scraping with explicit rate limiting to respect the BCRP server. The collection process is fully documented and replicable using the code provided in this repository.

## Reproducibility

### Complete Replication

The entire dataset can be reproduced from scratch using the code in this repository:

```bash
# Clone repository
git clone https://github.com/JasonCruz18/peru_gdp_revisions.git
cd peru_gdp_revisions

# Install dependencies
pip install -r requirements.txt

# Configure (optional - defaults work out of the box)
cp config/config.example.yaml config/config.yaml

# Run complete pipeline
python scripts/update_rtd.py
```

**Expected Runtime**: 30-45 minutes (first run)
**Internet Required**: Yes (to download PDFs from BCRP)
**Storage Required**: ~2 GB (including dependencies)

### System Requirements

- **Operating System**: Windows 10+, macOS 10.14+, or Linux (Ubuntu 18.04+)
- **Python**: Version 3.10 or higher
- **Java**: JRE (Java Runtime Environment) for PDF processing
- **Browser**: Chrome, Firefox, or Edge (for web scraping)
- **RAM**: Minimum 4 GB (8 GB recommended)
- **Disk Space**: 2 GB free space

### Software Dependencies

All dependencies are listed in `requirements.txt` and include:
- `selenium` - Web scraping
- `tabula-py` - PDF table extraction
- `pandas` - Data manipulation
- `pyyaml` - Configuration management
- `tqdm` - Progress tracking

Full list with pinned versions available in `requirements.txt`.

## Data Quality

### Validation

All datasets undergo automated quality checks including:
- Missing value analysis
- Value range validation (GDP growth typically -20% to +20%)
- Duplicate detection
- Time series continuity checks
- Index monotonicity verification

Run validation yourself:
```bash
python scripts/validate_rtd.py --verbose --export-report
```

### Known Limitations

1. **Historical Data (pre-2013)**: Scanned PDFs may have OCR errors
2. **Base-Year Changes**: Peru changed base years multiple times (1990, 1994, 2007), causing structural breaks
3. **Missing Observations**: Some periods may be missing if not published in Weekly Reports
4. **Revision Timing**: Exact timing of some revisions may be approximate

### Data Processing

The pipeline applies 70+ automated cleaning functions including:
- Text normalization
- Sector name standardization
- Numeric conversion
- Outlier detection
- Format harmonization

Full methodology documented in:
- `docs/ARCHITECTURE.md` - Technical implementation
- `notebooks/` - Step-by-step tutorials

## Updates

### Update Frequency

The BCRP publishes Weekly Reports every week. To incorporate new data:

```bash
python scripts/update_rtd.py
```

The pipeline is idempotent and will:
- Download only new PDFs
- Skip already processed files
- Update existing datasets

### Version Control

Dataset versions are tracked via:
- Git commits (code and metadata)
- GitHub releases
- Semantic versioning (MAJOR.MINOR.PATCH)
